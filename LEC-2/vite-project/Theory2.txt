# 📘 Lecture 54 – React Components & Babel (React 19)

## 🚀 1. What Are Components in React?

**Definition:**
Components are the **building blocks** of a React application.
Each component is an **independent, reusable piece of UI** that can manage its own state and logic.

### 🧩 Types of Components

#### 1. Functional Components (Modern Approach ✅)

* Introduced as simple JavaScript functions.
* Can use **Hooks** (like `useState`, `useEffect`) for state and lifecycle management.

**Example:**

```jsx
import React, { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0); // React Hook for state

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Increase</button>
    </div>
  );
}

export default Counter;
```

#### 2. Class Components (Older Approach ❌)

* Use ES6 `class` syntax.
* Manage state using `this.state` and lifecycle methods (`componentDidMount`, etc.).

**Example:**

```jsx
import React, { Component } from "react";

class Counter extends Component {
  constructor() {
    super();
    this.state = { count: 0 };
  }

  increment = () => this.setState({ count: this.state.count + 1 });

  render() {
    return (
      <div>
        <h2>Count: {this.state.count}</h2>
        <button onClick={this.increment}>Increase</button>
      </div>
    );
  }
}

export default Counter;
```

🟢 **In React 19**, **functional components with hooks** are preferred.

## ⚙️ 2. Component Composition

You can **combine components** to build complex UIs.

**Example:**

```jsx
function Header() {
  return <h1>Welcome to My App</h1>;
}

function Footer() {
  return <footer>© 2025 MyApp</footer>;
}

function App() {
  return (
    <div>
      <Header />
      <p>This is the main content.</p>
      <Footer />
    </div>
  );
}

export default App;
```

🧠 **Concept:**
This is called **component composition** — small UI parts combined to make a large UI.

## ♻️ 3. Reusability in React

* Components can accept **props** to make them **reusable**.

**Example:**

```jsx
function Button({ text, color }) {
  return <button style={{ backgroundColor: color }}>{text}</button>;
}

function App() {
  return (
    <div>
      <Button text="Login" color="green" />
      <Button text="Signup" color="blue" />
    </div>
  );
}
```

## 🔁 4. React Hooks (React 19 Essentials)

### 🧠 `useState`

Used for managing component state.

```jsx
const [value, setValue] = useState("Hello");
```

### ⚙️ `useEffect`

Used for side effects — API calls, timers, etc.

```jsx
import { useEffect } from "react";

useEffect(() => {
  console.log("Component mounted");
  return () => console.log("Component unmounted");
}, []);
```

### 💡 `useMemo` (Performance Optimization)

Used to **memoize** (cache) expensive computations.

```jsx
import { useMemo, useState } from "react";

function ExpensiveCalculation({ num }) {
  const result = useMemo(() => {
    console.log("Calculating...");
    return num * 1000;
  }, [num]);

  return <p>Result: {result}</p>;
}
```

## 🧠 5. Redux Toolkit (React State Management)

Redux Toolkit simplifies global state management.

**Install:**

```bash
npm install @reduxjs/toolkit react-redux
```

**Example:**

```jsx
// store.js
import { configureStore, createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: "counter",
  initialState: { value: 0 },
  reducers: {
    increment: state => { state.value += 1; },
    decrement: state => { state.value -= 1; },
  }
});

export const { increment, decrement } = counterSlice.actions;
export const store = configureStore({ reducer: { counter: counterSlice.reducer } });
```

```jsx
// App.js
import React from "react";
import { Provider, useSelector, useDispatch } from "react-redux";
import { store, increment, decrement } from "./store";

function Counter() {
  const value = useSelector(state => state.counter.value);
  const dispatch = useDispatch();
  return (
    <div>
      <h2>{value}</h2>
      <button onClick={() => dispatch(increment())}>+</button>
      <button onClick={() => dispatch(decrement())}>-</button>
    </div>
  );
}

export default function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}
```

## 🧩 6. Babel in React

**Babel** is a **JavaScript compiler** that converts **modern JS (ES6+)** code into **older browser-compatible ES5 code**.

### Why Babel?

React uses JSX syntax (HTML + JS). Browsers don’t understand JSX — Babel converts it to plain JS.

**Example:**

JSX Code:

```jsx
const element = <h1>Hello, World!</h1>;
```

Babel Converts to:

```js
const element = React.createElement("h1", null, "Hello, World!");
```

## ⚙️ 7. Babel Configuration

**Installing Babel:**

```bash
npm install @babel/core @babel/preset-env @babel/preset-react babel-loader --save-dev
```

**.babelrc File:**

```json
{
  "presets": ["@babel/preset-env", "@babel/preset-react"]
}
```

**In Webpack Config:**

```js
module: {
  rules: [
    {
      test: /\.(js|jsx)$/,
      exclude: /node_modules/,
      use: {
        loader: "babel-loader"
      }
    }
  ]
}
```

## 🆕 8. React 19 Features (Highlights)

| Feature                         | Description                                                    |
| ------------------------------- | -------------------------------------------------------------- |
| 🧩 **React Compiler**           | Automatically optimizes components, no need for memo manually. |
| ⚛️ **Actions API**              | Simplifies async form actions and server updates.              |
| 🌐 **use() Hook**               | Awaits Promises directly in components.                        |
| 🪄 **Better SSR/Streaming**     | Faster server rendering and hydration.                         |
| 🎯 **Improved Suspense**        | Smooth loading of async components.                            |
| 💬 **New Context API Upgrades** | Optimized re-renders and performance.                          |
